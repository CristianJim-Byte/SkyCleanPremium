🖼️ SkyClean — Guía de Optimización de Imágenes

Las fotos actuales son de alta resolución (stock UTC). Sigue estos pasos para optimizarlas y acelerar la carga de la web.

OPCIÓN A Squoosh (más fácil, sin instalar nada)

Abre squoosh.app en tu navegador. Arrastra cada imagen, elige WebP con calidad 75-80 y descárgala. Guárdala en la misma carpeta Udrone/ con extensión .webp.

OPCIÓN B Comando rápido (si tienes Node.js)

Instala sharp-cli y convierte todas las imágenes de golpe:

cd C:\Users\amber\Desktop\SkyCleanPremium

npx sharp-cli --input "Udrone/*.jpg" --output "Udrone/optimized/" --format webp --quality 78 --resize 1920
npx sharp-cli --input "Udrone/*.JPG" --output "Udrone/optimized/" --format webp --quality 78 --resize 1920

Esto creará versiones WebP de max 1920px de ancho con ~78% calidad — perfecto para web.

OPCIÓN C Python (si tienes Python instalado)

pip install Pillow

python -c "
from PIL import Image
import glob, os

os.makedirs('Udrone/optimized', exist_ok=True)
for f in glob.glob('Udrone/*.jpg') + glob.glob('Udrone/*.JPG'):
    img = Image.open(f)
    img.thumbnail((1920, 1920), Image.LANCZOS)
    name = os.path.splitext(os.path.basename(f))[0]
    img.save(f'Udrone/optimized/{name}.webp', 'webp', quality=78)
    old_size = os.path.getsize(f) / 1024
    new_size = os.path.getsize(f'Udrone/optimized/{name}.webp') / 1024
    print(f'{name}: {old_size:.0f}KB -> {new_size:.0f}KB ({(1-new_size/old_size)*100:.0f}% smaller)')
"

DESPUÉS Actualizar index.html

Una vez optimizadas, cambia las rutas en index.html. Por ejemplo:


<img src="Udrone/close-up-of-a-surveillance-drone...utc.jpg">


<img src="Udrone/optimized/close-up-of-a-surveillance-drone...utc.webp">

O usa <picture> para compatibilidad total:

<picture>
  <source srcset="Udrone/optimized/close-up...webp" type="image/webp">
  <img src="Udrone/close-up...jpg" alt="...">
</picture>
